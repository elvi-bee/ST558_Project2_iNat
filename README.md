# ST558_Project2_iNat
ST 558 Project 2: Shiny App featuring iNaturalist data. 
Created: November 2025
Created by:Elvira McIntyre
Summary: The app focuses on bird observations (Aves) recorded through the iNaturalist platform between 2020 and 2025 across counties in Western North Carolina (WNC). It enables users to visualize quantitative,spatial, temporal, and taxonomic patterns in the data and examine how observation effort and data quality vary over time.
